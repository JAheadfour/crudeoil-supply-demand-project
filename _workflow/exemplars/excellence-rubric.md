# Oil 101 理解版质量 Rubric（候选 v1）

锚点候选：`course/data/oil101-understanding/module-05-inventory-curve.json`。

状态：完整样课已经生成并通过机械地板，但尚未获得用户对完整成品的签收。签收前仅用于校准，不得据此批量生产。

## D1 主线先行

要求：开篇必须把本模块放回“物理流 → 库存 → 价差 → 价格 → 行动”的全书主线。

- 通过：读者在看到术语前，已经知道本课要解释哪个现实问题及其所在环节。
- 不通过：用“本章介绍定义、类型和应用”代替主线。
- 反作弊：章节目录改写成一段话不算主线，必须出现因果关系与决策用途。

## D2 概念三件套

要求：每个核心概念包含英文名、中文名和可判别定义，再展开直觉。

- 通过：定义能让读者判断一个新案例是否属于该概念。
- 不通过：“Contango 是一种重要的市场结构。”
- 反作弊：万能句式或同义反复不算定义。

## D3 机制链

要求：每个核心单元至少包含三步真实因果传导，并说明中间条件。

- 通过：炼厂检修 → 原油投入下降 → 原油累库/产品去库 → 原油月差与裂解价差分化。
- 不通过：在三个定义之间添加“因此”。
- 反作弊：每一步必须改变状态或约束，不能只换措辞。

## D4 现实推演

要求：每个核心概念配具体情境、至少两步过程和明确结论。

- 通过：给定到港、加工与库存组合，逐步判断是物流时点还是结构过剩。
- 不通过：“贸易商可以利用期货管理风险。”
- 反作弊：只出现人物或数字但没有过程不算案例。

## D5 多信号市场判断

要求：市场结论必须同时连接库存构成、地点、价差、现货或物流中的至少三类证据。

- 通过：结论包含支持证据、反证和下一次验证条件。
- 不通过：库存增加，所以油价下跌。
- 反作弊：多个来自同一数据表的高度相关分项不能冒充独立证据。

## D6 误读与边界

要求：每课写出具体错误推理，以及概念不适用或可能失效的条件。

- 通过：说明 Contango 为什么不是未来现货上涨预测，并指出库容/信用受限时套利失效。
- 不通过：“读者可能理解不深。”
- 反作弊：泛泛提醒风险不算边界，必须写明前提何时不成立。

## D7 原图与 Reference

要求：只使用承担解释作用的原图；正文先教怎么看，图后说明证明什么与不能证明什么，并附章节、图名、原链接和访问日期。

- 通过：Oil 101 Figure 18-1 放在负油价机制旁，图前提示比较临期与远月。
- 不通过：把整页网页截图放在章末，或只有“来源：网络”。
- 反作弊：装饰性图片、不可读缩略图和无正文解读的图片不计入覆盖。

## D8 心智模型压缩

要求：结尾至少四条可脱稿复述的判断点和一句总模型。

- 通过：读者能用该模型处理未在原书出现的新场景。
- 不通过：重复学习目标或标题。
- 反作弊：口号式短句不算判断规则。

## D9 应用触发器与自检

要求：至少三个“看到什么 → 先做什么”的应用触发器，以及五个带要点对照的合书自检。

- 通过：看到 EIA 累库时，先拆进口、出口和 runs，再看 Cushing、产品与月差。
- 不通过：“需要时使用本章知识。”
- 反作弊：自检不能退化成原句填空或选择题。

## D10 来源忠实与事实核验

要求：案例与术语口径可追溯；不虚构作者经历、数据或事件。

- 通过：负油价结算值与交割机制分别核对 Oil 101 和 EIA 原始页面。
- 不通过：为了让故事顺滑而补写未经来源支持的精确数字。
- 反作弊：引用链接存在不等于事实已核对，盲审需抽查至少三个案例事实与两个术语。

## D11 手机阅读质量

要求：390px 宽度无页面横向溢出；正文、表格、图、按钮和引用均可读可点。

- 通过：课程导航横向滚动但不撑宽页面，原图缩放到内容宽度，自检状态可持久化。
- 不通过：单字孤行、图表溢出、按钮文字被截断或交互造成布局跳动。
- 反作弊：仅检查 HTML 结构或桌面截图不能判定通过，必须用真实手机视口操作。

## 判定规程

逐维 PASS/FAIL；FAIL 必须引用候选中的具体内容并给出定向修复。机械字段齐全、字数达标或测试全绿只能证明下限，不构成最终 PASS。完整样课经用户签收后，复制为中性文件名交给独立判官，与后续候选逐模块并排比较。
