# Oil 101 内容重写设计

## 目标

把现有 Oil 101 学习平台从“高密度行业笔记”重写成“懂经济金融、但不懂石油行业的读者可以独立读懂的行业课程”。重写必须保留原版网页的关键事实、机制、数字、图表和边界，但不能要求读者预先理解石油物理链条、行业角色或交易惯例。

第一阶段只重写 Module 01，形成可供用户实际阅读和确认的金标准。Module 01 通过后，再把同一标准应用到其余八个模块。

## 读者基准

可以假设读者已经理解：

- 基本供需关系、价格与成本；
- 企业收入、利润、现金流和风险；
- 期货、库存、套利等金融概念的基础含义。

不能假设读者已经理解：

- 原油在地下以什么形态存在；
- 油井、井场、集输、管道、罐区和炼厂分别做什么；
- API gravity、sulfur、assay、stream、blend、grade 等行业术语；
- WTI、Cushing、实物交割和炼厂装置的行业背景；
- 石油行业的参与者、合同、规格和物流惯例。

## 核心原则

### 1. 先建立对象，再给术语

任何专业术语第一次出现时，必须先说明它指向的真实对象、发生地点、参与者和用途，然后才给出中文名称及英文术语。禁止用尚未解释的新术语定义另一个新术语。

### 2. 一次只增加一个主要认知负担

一句话不得同时要求读者掌握多个新概念。较长的因果关系应拆成短段落或编号步骤，每一步明确说明“发生了什么”和“为什么会导致下一步”。

### 3. 从物理现场连接到经济结果

每个概念都必须回答两类问题：

- 现实中谁在什么地方做什么；
- 这件事如何影响成本、产量、库存、价差、利润、风险或价格。

### 4. 深度分层，而不是删除深度

核心正文负责建立直觉和主机制；技术口径、例外、规格细节和行业争议进入“深入一层”。读者跳过深入部分后仍能理解主线，阅读深入部分则能恢复原书的重要细节。

### 5. 原版网页仍是唯一主输入

重写继续直接依据 Morgan Downey 的 Oil 101 当前网页版本。旧课程 JSON 只作为待改稿和漏项检查材料，不得作为事实来源。时效性数字和预测继续按现有规则独立核验或明确延期。

## 每节课的教学结构

每个 lesson 按以下顺序重写：

1. **这一节要解决什么困惑**：用读者会自然提出的问题开场。
2. **先看真实场景**：交代地点、物体、参与者和动作。
3. **一句话答案**：在场景建立后给出主结论。
4. **一步步讲机制**：每步只引入一个主要变化，并解释因果连接。
5. **用数字走一遍**：用桶数、价格、时间、距离、收率或成本完成一个具体例子。
6. **它为什么影响市场**：连接到企业经营或市场分析。
7. **专业语言对照**：集中整理本节首次出现的中英文术语。
8. **容易误会什么**：指出直觉最容易出错的地方。
9. **深入一层**：承载规格、边界、例外和原书中的技术细节。
10. **读完检查**：用一个无需背诵、但必须真正解释机制的问题收尾。

## 表达规则

- 以自然中文为主。英文只在首次定义、行业报价或无法准确替代时保留。
- 禁止在同一句中连续堆叠三个以上未解释的英文术语。
- 句子优先控制在一个主要判断内；因果链使用短段落或编号。
- 类比只能用于建立直觉，必须紧接着说明类比在哪些地方不成立。
- 数字例子必须说明单位、角色、输入、计算过程和结论。
- 不使用“显然”“不言而喻”等跳过推理的词。
- 不把 source coverage、生成校验或课程制作元数据展示给普通读者。

## Module 01 重写范围

Module 01 继续覆盖一桶油的完整物理旅程，但内容顺序调整为读者更容易建立模型的顺序：

1. 原油在地下究竟以什么形态存在；
2. 油井如何把地下流体带到地面；
3. 井场为什么必须先分离水、气和杂质；
4. 单个油井的原油怎样汇成可交易的商业油种；
5. 原油品质为什么会改变炼厂价值；
6. 炼厂如何把一桶原油变成不同产品；
7. 管道、油轮、铁路、卡车和储罐各自解决什么问题；
8. 地点、时间和可用设施为什么最终影响价格。

原有的 87 个原文 H2 覆盖记录继续保留在数据层，用来检查漏项；它不决定正文顺序，也不直接展示为学习内容。

## 数据与页面关系

Module 01 仍使用现有 JSON 驱动页面，但需要把学习正文与审计元数据分开：

- `lessons` 保存面向读者的分层讲解；
- `glossary` 保存已在正文中解释过的术语，不承担首次教学；
- `figures` 保留原图、读图顺序和来源；
- `source_coverage` 与 `source_anomalies` 只用于质量审计；
- 页面模板只展示有助于理解的内容，不展示制作流程字段。

如果现有字段无法表达新的教学顺序，可以为 lesson 增加清晰、通用的字段；不得把正文重新塞回单个超长 `explanation` 字符串。

## 验收标准

Module 01 只有同时满足以下条件才算通过：

### 可理解性

- 随机抽取任何一节，读者不依赖其他石油资料即可解释本节主机制；
- 每个首次出现的行业术语都能在出现位置附近找到自然语言解释；
- 不存在用多个未定义术语互相解释的句子；
- 每节至少有一个具体场景和一个完整数字例子。

### 教学质量

- 读者能说出物理过程如何传导到经济或市场结果；
- 核心正文和“深入一层”可以分别成立；
- 案例不要求读者预先了解 Cushing、WTI、炼厂装置或行业合同；
- 自检问题要求复述机制或判断新场景，而不是背定义。

### 来源完整性

- 继续直接追溯作者原版网页；
- 原有关键事实和原图不因口语化而丢失；
- 87 个 H2 均保持覆盖、延期或不采纳记录；
- 时效性强或无法核验的断言不作为确定事实进入正文。

### 产品验证

- canonical JSON 与发布镜像一致；
- 内容验证器通过；
- 桌面与手机均能完整渲染新增字段；
- 自动检查术语首次出现、空泛例子、乱码、资源缺失和页面错误；
- 用户实际阅读 Module 01 后明确确认其讲解方式可继续推广。

## 推进方式

1. 重新读取 Module 01 对应的作者原版网页；
2. 建立概念依赖顺序和术语首次出现表；
3. 按本设计重写 Module 01，不沿用旧句子的表达结构；
4. 做来源覆盖、内容验证和浏览器检查；
5. 请用户实际阅读样章并指出仍不清楚的位置；
6. 样章通过后，再制定其余八个模块的批量重写计划。
