# Oil 101 Episodes 02-19 蓝图

本文件定义每集的叙事任务，不是逐句脚本。制作资料包时必须重新读取所列原书章节，并用自己的中文教学语言重构。

## 02｜权力总在寻找一只阀门

- **原书**：Chapter 1；Chapter 5 只用于识别行业角色。
- **冷开场**：地下的油不会投票，为什么一百多年里却总有某个公司、州政府或国家集团能影响世界油价？
- **一句答案**：控制权属于当时能卡住扩产、运输或市场准入的主体；技术和基础设施变化会让这只“阀门”换手。
- **三个画面**：煤油灯旁的第一口商业井；被管线和炼厂连成一体的巨型网络；从 Texas Railroad Commission 到 OPEC、再到页岩响应的接力阀门。
- **主线**：需求出现 -> 规模网络形成 -> 反垄断与州级调节 -> 产油国夺回资源权 -> 价格冲击催生节约和新供给 -> 现代控制更分散。
- **本集不讲**：不念完整年代大事表；不展开 OPEC+ 配额；不解释压裂技术；不重讲井口混合流。
- **去重重点**：历史事件只在推动“控制点迁移”时出现，每个时代只留一个代表事件。

## 03｜一桶原油的身份证

- **原书**：Chapters 2、4。
- **冷开场**：两船原油体积一样，为什么炼厂可能抢一船、嫌另一船？
- **一句答案**：原油价值取决于它能产出什么、需要多少改造和清理，而 assay 与化学性质就是这笔加工账的身份证。
- **三个画面**：货物随身的化验单；从短到长的碳链楼梯；炼厂面对不同原油的购物清单。
- **主线**：assay 不是好坏评分 -> 密度和硫先给粗轮廓 -> TAN、金属、黏度等补充加工难度 -> 分子结构解释为何产率与处理成本不同 -> 质量差异进入价格。
- **本集不讲**：不背 API 公式；不列完所有 assay 项；不提前游览整座炼厂；不做原油价格计算。
- **去重重点**：每个性质只回答一次“它改变哪项加工结果”，不再用第二个定义复述。

## 04｜统计表里的油为什么越算越多

- **原书**：Chapter 3；Chapter 10 只用于说明 NGL 和石脑油的去向。
- **冷开场**：一个国家“原油产量没涨”，为什么“石油液体供应”仍可能增长？
- **一句答案**：统计中的 oil liquids 是多个来源和处理阶段的合计，不等于单一的传统原油流量。
- **三个画面**：桌上五个标签不同的量杯；把 NGL 分开的分馏列车；炼厂出口端比入口端体积略大的刻度杯。
- **主线**：先把 crude、condensate、NGL、非常规液体和 refinery gain 分开 -> 解释 NGL 分馏与 ethane rejection -> 说明体积增益不是凭空创造能量 -> 回到供应新闻的口径检查。
- **本集不讲**：不展开石化产品树；不讨论储量；不重讲井口三相流；不比较各机构具体统计表。
- **去重重点**：每类液体只给“来源 + 为什么会被计入/剔除”两项信息，不做产品百科。

## 05｜一口井背后为什么站着几十家公司

- **原书**：Chapters 5、6。
- **冷开场**：新闻只写某家石油公司发现了油，真正把油送到市场的为什么是一支合同和公司的接力队？
- **一句答案**：地下权利、地质判断、资本、钻完井、地面工程和销售能力由不同主体承担，产业结构就是风险分工。
- **三个画面**：一张勘探权合同；从地震资料到投产的接力棒；运营商身后的服务公司和工程承包商。
- **主线**：先取得权利 -> 选择合同与财政安排 -> 勘探降低地质不确定性 -> 开发方案承诺资本 -> 服务与工程公司完成专业动作 -> 生产商承担最终资产风险。
- **本集不讲**：不复述 Episode 01 的压力和井口流体；不讲炼厂流程；不做 NOC/IOC 排名；不展开衰减和页岩跑步机。
- **去重重点**：角色按“承担哪一种失败风险”介绍，不按公司类别逐个下定义。

## 06｜炼厂不是一个大过滤器

- **原书**：Chapter 7。
- **冷开场**：如果蒸馏只能把原油分开，汽油和柴油为什么不会永远受原油天然比例限制？
- **一句答案**：炼厂先分离，再改造、组合、清理和调和分子；利润主要来自把天然产率变成市场需要的产率。
- **三个画面**：按沸点分楼层的蒸馏塔；把大分子拆小、把低辛烷值结构改造的车间；最后按规格配方混合的调和罐。
- **主线**：feedstock 与 product slate 的冲突 -> distillation 做分离 -> conversion 改变分子大小 -> reforming/alkylation 改变质量 -> treatment 清除杂质 -> blending 才生成成品。
- **本集不讲**：不背装置清单；不详细比较全部炼厂复杂度指数；不列 19 种产品；不计算 crack spread。
- **去重重点**：每类工艺只回答“输入被怎样改变”，同一装置不从设备、化学、经济三个角度重复介绍。

## 07｜汽油不是一种液体

- **原书**：Chapters 8、9；Chapter 15 只用于解释法规为何进入规格。
- **冷开场**：同样叫汽油或柴油，为什么换一个季节、州或发动机就可能不能直接销售？
- **一句答案**：成品油是满足特定用途、地区和季节规格的配方商品，名称相同并不保证可替换。
- **三个画面**：产品随身的规格护照；炼厂调和台上的配方；同一油罐在季节切换前后的标签变化。
- **主线**：标准让交易成为可能 -> octane/cetane 等指标对应发动机需要 -> 挥发性、硫、低温和安全指标对应环境与使用条件 -> 不同产品族有不同规格 -> 规格改变物流可替代性。
- **本集不讲**：不罗列全部成品油；不深入发动机四冲程；不展开环境法规史；不讲零售税差。
- **去重重点**：选择汽油、柴油、航煤三个代表，不为每种产品重复“标准很重要”。

## 08｜石油需求不只在油箱里

- **原书**：Chapter 10；Chapter 3 用于 NGL 与石脑油来源。
- **冷开场**：即使汽车少烧汽油，为什么石油和天然气仍可能进入更多日常物品？
- **一句答案**：石脑油和轻质气体可以被裂解成少数基础分子，再沿产业树进入塑料、纤维、化肥和其他材料。
- **三个画面**：石脑油与乙烷两扇原料门；六个基础分子的树干；从树枝长出的包装、衣物和化肥。
- **主线**：两条主要原料路线 -> 基础 building blocks -> ethylene/propylene/aromatics 价值链 -> 天然气优势与地区成本 -> 石化需求和燃料需求并非同一速度。
- **本集不讲**：不做聚合物大全；不讨论塑料政策立场；不提前争论峰值需求；不重讲 oil liquids 统计口径。
- **去重重点**：只追踪两条代表链，不对每个终端产品重新从原料讲起。

## 09｜油不会自己流到缺油的地方

- **原书**：Chapter 11。
- **冷开场**：世界总供应充足，为什么一个港口、机场或内陆地区仍会突然缺油？
- **一句答案**：油必须匹配路线、运力、基础设施、合同和接收条件；全球桶数不能瞬间跨越本地瓶颈。
- **三个画面**：固定方向和容量的管线网；跨洋油轮与狭窄海峡；把货送到最后一段的铁路或卡车。
- **主线**：五种运输方式各有经济半径 -> 船运与租船决定跨洋弹性 -> 管线高效但路径固定 -> 铁路和卡车补灵活性 -> chokepoint 与 hub 让地点成为约束。
- **本集不讲**：不计算 Worldscale；不展开 Incoterms 条款表；不讲完整霍尔木兹案例；不进入价格 netback。
- **去重重点**：运输方式用“最适合解决什么问题”比较，不逐个重复成本、速度、风险三张清单。

## 10｜储罐是市场的时间机器

- **原书**：Chapters 12、13。
- **冷开场**：今天多出来的油没有消失，它去了哪里，又为什么几个月后会反过来影响价格？
- **一句答案**：库存把当期盈余搬到未来、把过去库存释放到今天，而季节日历决定何时需要这座时间桥。
- **三个画面**：一只会涨落的储罐水位；叠在一起的驾驶、取暖、检修和天气日历；库容接近上限时越来越窄的入口。
- **主线**：商业库存的缓冲作用 -> 地上罐、盐穴、浮仓与战略储备的不同任务 -> 库存报告 -> 四类季节性日历 -> 炼厂检修和产品需求怎样传回原油库存。
- **本集不讲**：只用一句预告 contango，不解释期货曲线；不重讲物流方式；不展开负油价事件。
- **去重重点**：每一种季节因素必须落到“哪类库存先变”，否则删掉。

## 11｜地下有很多油，供应为什么还会掉

- **原书**：Chapters 14、21；Chapter 6 用于项目与递减背景。
- **冷开场**：一个国家储量巨大，为什么明年的产量仍可能下降？
- **一句答案**：地下总量必须经过经济、技术、许可、资本和时间筛选；投产后还有自然递减，页岩只是把补产节奏加快而没有取消递减。
- **三个画面**：resource 到 reserve 再到 production 的多级阶梯；不断下滑的老井曲线；必须持续钻井才能维持高度的页岩跑步机。
- **主线**：三类储量与开发状态 -> 储量会重分类 -> 项目时钟与资本承诺 -> decline curve -> 页岩水平井与压裂缩短响应 -> 单井快速递减迫使持续补井 -> 供应弹性有速度边界。
- **本集不讲**：不复述井口处理；不做各国 R/P 排名；不详细讲 frac job；不讨论 OPEC+ 配额。
- **去重重点**：储量和页岩只在同一条“何时能形成持续流量”主线上相遇，不各自再总结一次。

## 12｜一桶油为什么没有一个价格

- **原书**：Chapter 17；Chapters 2、8、11 只调用已建立的质量与地点概念。
- **冷开场**：电视屏幕只有一个 WTI 或 Brent 数字，实际成交的几百种原油价格从哪里来？
- **一句答案**：基准提供共同锚点，实际价格再按质量、地点、时间、运输和合同条件加减。
- **三个画面**：一枚公开基准价标签；围绕标签增减的质量和地点账本；从目的地倒推运费的 netback 地图。
- **主线**：physical barrel 与 benchmark -> delivery-chain price ladder -> formula pricing 的结构 -> freight netback -> pricing window 与报告机构 -> 为什么零售价又是另一层。
- **本集不讲**：不要求单位换算；不做复杂公式价格例题；不解释整条期货曲线；不预测油价。
- **去重重点**：质量和运输只作为一个调整项调用，不重新解释 assay 或船运。

## 13｜期货曲线不是价格预言

- **原书**：Chapter 18、Appendix 1；Chapter 12 提供储存直觉。
- **冷开场**：远月比近月贵，市场是在预言以后一定涨价吗？
- **一句答案**：期货曲线首先反映不同交割时间的库存、融资、便利收益和即时稀缺约束，不是单纯预测图。
- **三个画面**：摆在不同月份的两桶油；到期必须决定去向的交割时钟；连接今天和未来的储存桥。
- **主线**：paper barrel 与 wet barrel -> contango/backwardation -> storage economics -> calendar spread -> WTI/Brent 交割机制 -> futures 与 swaps 如何把价格风险跨时间转移。
- **本集不讲**：不展开期权；不做 crack spread 算题；不复述 Cushing 全部基础设施；不声称曲线完全不含预期。
- **去重重点**：曲线形状只解释一次，后续案例必须说明新增的交易或物理含义。

## 14｜锁住价格，为什么仍可能缺现金

- **原书**：Chapters 19、20；Chapter 18 只用于工具连接。
- **冷开场**：一家公司说“已经对冲”，为什么油价大动时仍可能亏损、补保证金或现金紧张？
- **一句答案**：对冲只改变特定价格暴露；基差、数量、期限、保证金、对手方和运营风险仍会留下不同现金流路径。
- **三个画面**：有免赔额和上限的保险菜单；现货地点与对冲基准之间的缝隙；价格逆向移动时提前到来的保证金日历。
- **主线**：先问企业真正怕什么 -> swap、put、collar 的不同承诺 -> basis 与 volume mismatch -> roll 和 liquidity -> counterparty/ISDA -> hedge accounting 与治理 -> 为什么不对冲也可能是选择。
- **本集不讲**：不推导 Black-76；不背 Greeks；不要求计算 payoff；历史事故只选一个说明现金流错配。
- **去重重点**：每种工具只回答“牺牲什么换来什么”，不再分别复述保险比喻。

## 15｜一纸减产能少掉多少真实桶

- **原书**：Chapter 22；Chapters 5、14 只提供主体和口径背景。
- **冷开场**：OPEC+ 宣布减产两百万桶，为什么市场可能只相信其中一部分？
- **一句答案**：公告必须经过 baseline、真实能力、已有限制、执行和出口条件，才能变成市场真正少掉的桶。
- **三个画面**：决定起点的 baseline 尺子；可以压下再释放的 spare-capacity 弹簧；逐国兑现的 compliance 记分牌。
- **主线**：OPEC 到 OPEC+ -> 谁拥有可持续余量 -> quota/baseline -> overcompliance 与作弊 -> Saudi/Russia 的不同约束 -> 价格、份额和财政之间的战略权衡。
- **本集不讲**：不重讲完整石油史；不逐国报产量；不把名义能力当闲置产能；不讨论海峡封锁。
- **去重重点**：所有政治叙述必须落回“真实桶数怎样变化”，否则不进入节目。

## 16｜油价为什么能跌到零以下

- **原书**：Chapter 23；Chapters 12、18 只调用库存和交割机制。
- **冷开场**：油是有用的商品，卖方为什么会付钱请别人接走？
- **一句答案**：临近到期的合约要求实物接收，而当合格库容和退出通道同时耗尽，摆脱交割义务本身会变得有价值。
- **三个画面**：即将过期的交割票；接近罐顶的 Cushing 储罐；大量持仓挤向一扇很窄的出口门。
- **主线**：WTI delivery obligation -> 疫情需求崩塌与库存上升 -> front-month 拥挤 -> 到期日时间压力 -> 负价形成 -> 规则和产品改革 -> 事件揭示金融价格的物理底座。
- **本集不讲**：不完整复述疫情史；不堆每分钟价格；不把负价格解释成所有原油都没人要；不展开电力负价。
- **去重重点**：只在三个时间点推进故事，避免多次用“库容满了”解释同一结果。

## 17｜美国天然气怎样进入全球价格

- **原书**：Chapter 24；Chapter 11 只提供船运背景。
- **冷开场**：美国内陆管道里的天然气，怎样影响欧洲和亚洲买家的价格？
- **一句答案**：液化、专用船、再气化和长期合同把区域管道市场连接起来，但设施容量和运费让全球价格仍不会完全相同。
- **三个画面**：把气体压缩成液体体积的液化列车；跨洋 LNG 船；Henry Hub、TTF、JKM 三块相互看得见但不重合的价格屏。
- **主线**：从进口设想到出口能力 -> 液化设施与第二波项目 -> cargo destinations -> 合同定价 -> 船与航线瓶颈 -> 欧洲 FSRU -> Henry Hub 全球化及其边界。
- **本集不讲**：不做天然气工程课；不重讲全部油轮类型；不把 LNG 和原油当同一市场；不预测项目投产日期以外的价格。
- **去重重点**：每次提到三地价格必须新增一个连接成本或容量边界，不能只说“市场更全球化”。

## 18｜峰值需求不是突然不用油

- **原书**：Chapters 15、16、25；Chapters 9、10 只调用燃料和石化需求差异。
- **冷开场**：电动车销量增长，为什么石油需求不会在某一年像开关一样关闭？
- **一句答案**：法规先改变燃料和设备要求，技术改变单位服务耗油量，车队与工业资本再缓慢更新；不同地区和用途因此以不同速度转型。
- **三个画面**：法规写进燃料和尾气系统的接口；把输入能量分去动力与热损失的发动机图；旧车逐年退出、新车逐年进入的车队传送带。
- **主线**：污染物规则推动燃料与催化器协同 -> 发动机效率与混动 -> EV/氢能的适用边界 -> OECD 与非 OECD 差异 -> 石化和重载需求 -> 可再生能源与天然气悖论 -> 投资不足可能在需求放缓前制造供给紧张。
- **本集不讲**：不列政策年份大全；不做车型优劣辩论；不押注峰值年份；不把所有石油需求等同乘用车。
- **去重重点**：法规、技术和车队各讲一个传导阶段，不用三套语言重复“需求下降很慢”。

## 19｜一条海峡怎样震动整条产业链

- **原书**：Chapter 26；Chapters 11、12、22 只调用运输、库存和产量管理机制。
- **冷开场**：一艘船还没沉、一口井也没坏，为什么海峡受阻就能迫使产油国减产并让远方买家抢油？
- **一句答案**：出口通道受阻会先改变船舶、保险和航线，再填满产区储罐、迫使上游降流，并把买家分成可获得替代桶和无法获得替代桶的两层市场。
- **三个画面**：全球油流地图上的窄门；窄门后方逐渐填满的储罐；绕行能力不同形成的两层买家地图。
- **主线**：chokepoint 暴露 -> 航运与保险反应 -> bypass pipelines 的上限 -> 产区库存和 forced shut-ins -> strategic stocks 与需求反应 -> reopening 不是瞬时恢复 -> 用完整传导链回看前 18 集。
- **本集不讲**：不重新教授 tanker、storage 或 OPEC+；不把书中的 2026 情景外推成永久事实；不做地缘政治立场评论。
- **去重重点**：这是调用旧模型的综合案例，每个旧概念只用一句，篇幅留给概念之间的先后顺序。
