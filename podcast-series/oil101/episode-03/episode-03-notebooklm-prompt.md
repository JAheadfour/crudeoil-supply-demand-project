# NotebookLM Audio Overview Prompt - Oil 101 Episode 03

请基于上传的唯一来源，生成一集 **12-15 分钟、简体中文、男女双人 Deep Dive** 科普播客。

声音和互动延续本账号已经通过用户认可的 Oil 101 Episode 01 V2：自然男女声，一方搭建行业机制，一方代表聪明但第一次接触炼油行业的听众。对话要像两个人共同拆开一张真实货单，不要像老师照着课件讲化学，也不要考听众。

## 这一集只解决一个问题

同样体积的两批原油，为什么炼厂愿意支付的价格会不同？

只保留一条价值主线：assay 先提示这桶油天然能产出什么，再提示把它变成合格产品要付出哪些处理代价；最终价值还取决于这桶油是否适合具体炼厂的设备。

## 三段推进

1. 从两艘油轮和两张货单开始。解释 assay 是商业原油的身份证，而不是颜色判断或统一好坏分数；用 off spec 的后果说明炼厂为什么认真看它。
2. 用“碳链梯子”解释分子较短通常沸点较低、较接近轻质产品，分子较长通常更多落入重质部分。PONA 只用来说明分子形状也会改变性质，不展开分子式和命名。
3. 把硫、TAN、金属、黏度、凝点、盐和水放进“加工账单”。最后进入炼厂购物清单：预期产品价值减去处理与适配成本，解释轻甜更容易卖，但复杂炼厂有时能从折价重酸原油中创造价值。

## 三个记忆画面

- 写满可验证特征的原油护照；
- 从短而轻到长而重的碳链梯子；
- 左边是产品、右边是处理成本的炼厂购物清单。

## 去重复硬约束

- 核心结论只在开场问题和结尾落点完整表达。中段每次接话都必须增加一个新的物性、成本或炼厂匹配机制。
- 三个画面各解释一次。结尾最多用一句把它们连起来，不逐个重讲。
- 主持人 B 不复述主持人 A 刚说完的句子；B 应提出真实的新困惑，例如“为什么密度只能做粗略判断”或“为什么复杂炼厂反而会买更难处理的油”。
- 每个属性只回答它新增了哪类约束。硫、TAN、金属和黏度不要分别重复“会让原油更便宜”。
- 删除只是在换词表达“不同原油价值不同”的段落。
- 结尾只完成一次判断，不另设独立总结段。

## 表达要求

- 不出题，不让听众停下来回忆，不要求计算。
- 不朗读 API 公式、PONA 比例表、元素含量表或原油等级数字清单。
- 英文术语第一次出现时用一句白话说明，之后优先说中文。保留 assay、API gravity、sweet、sour、TAN、PONA、off spec 即可。
- 不做炼厂设备游览。焦化、加氢裂化、催化裂化等只作为“某些炼厂拥有的处理能力”一笔带过。
- 不说轻甜原油永远更贵，也不说重酸原油是废料；始终把价值放回具体炼厂和处理成本。
- 允许自然惊讶和短反应，但不要段子化，不伪造亲历场景。

## 结尾

自然回到两艘油轮。让主持人 B 明白：以后看到一种原油折价，先不要问它是不是差油，而要问它会产出什么、需要处理什么、哪些炼厂能接。主持人 A 用一句话收束：原油护照写的是分子和杂质，炼厂真正读出来的却是一张未来利润表。
